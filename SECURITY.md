# Security Policy

## Reporting a vulnerability

Please report security issues **privately** through GitHub's private vulnerability reporting for this repository:

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, its impact, and steps to reproduce.

Please do **not** open a public issue or pull request for a suspected vulnerability.

## Scope

In scope: the on-chain program source in `programs/offchart-lite`, deployed at
`8vbugQ1PoVv3f3c5X1Np1K4s56juC72VMSKhtBp9bo2P` on Solana mainnet.

## Status of the program

The program has **not been audited**, and it is **upgradeable**. See the
[disclaimer in the README](README.md#disclaimer) before interacting with it.
